# GeoHub Garissa - AI-Driven Resilience Platform

An Integrated Geospatial AI Platform for Sustainable Development in Garissa County, Kenya.

![GeoHub Garissa](https://img.shields.io/badge/Version-2.5-blue.svg)
![Node.js](https://img.shields.io/badge/Node.js-18.x-green.svg)
![Express](https://img.shields.io/badge/Express-4.x-lightgrey.svg)

## 🌟 Features

- **Interactive Dashboards**: Climate monitoring, disaster early warning, refugee camp resilience, humanitarian planning, and rangeland management
- **AI-Powered Chatbot**: Multilingual assistant (English, Kiswahili, Somali) with voice input
- **Real-time Data**: Integration with Google Earth Engine and satellite data
- **Report Generation**: Automated PDF reports for various metrics
- **Weather Integration**: Current conditions and forecasts for Garissa County
