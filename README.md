# GeoHub Garissa - AI-Driven Resilience Platform

An Integrated Geospatial AI Platform for Sustainable Development in Garissa County, Kenya.

## Features

- **Interactive Dashboards**: Climate monitoring, disaster early warning, refugee camp resilience
- **AI-Powered Chatbot**: Multilingual assistant (English, Kiswahili, Somali)
- **Real-time Data**: Integration with Google Earth Engine
- **Report Generation**: Automated PDF reports
- **Weather Integration**: Current conditions and forecasts

## Quick Start

### Prerequisites
- Node.js (v18 or higher)
- Google Gemini API key

### Installation
1. Clone the repository: `git clone https://github.com/jmsmuigai/GeoHub-Garissa.git`
2. Setup backend: `cd backend && npm install`
3. Configure: `cp .env.example .env` and add your API key
4. Start server: `npm start`
5. Open `public/index.html` in your browser

## Configuration
Get your Gemini API key from [Google AI Studio](https://aistudio.google.com/)
